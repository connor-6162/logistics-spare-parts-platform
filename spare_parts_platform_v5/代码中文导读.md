# 备品备件平台代码中文导读

本文档与源代码中的中文注释配合使用，帮助读者快速理解“每一部分做什么、通过什么方式实现”。

## 1. 运行链路

1. Windows 计划任务执行 `deployment/windows/start_server.ps1`。
2. 启动脚本加载服务器上的 `production.env.ps1`，然后运行 `serve.py`。
3. `serve.py` 使用 Waitress 在本机端口托管 `app.py` 中的 Flask 应用。
4. Cloudflare Tunnel 把公网 HTTPS 请求转发到本机应用端口。
5. Flask 根据 URL 调用路由，从 SQLite 查询或更新数据，再通过 Jinja2 模板返回 HTML。
6. `static/app.js` 增强弹窗、表单联动和 AI 问答；`static/style.css` 负责桌面和移动端布局。

## 3. `app.py` 结构

### 3.1 配置

- `env_flag()`：把环境变量转换为布尔值。
- `app.config`：配置数据库、上传大小、Cookie 和首选协议。
- AI 参数：从环境变量读取提供商、账户、令牌、模型、超时和限流值。
- `DEMO_MODE`：演示环境启动时恢复七类演示账户；生产环境应关闭。

### 3.2 角色权限

- `ROLE_NAMES`：七类岗位的中英文名称。
- `ROLE_PERMISSIONS`：每类岗位允许执行的服务器端动作。
- `has_permission()`：检查角色权限。
- `permission_required()`：装饰 Flask 路由；无权限直接返回 403。
- 页面隐藏按钮只是用户体验，真正的安全边界始终在服务器。

### 3.3 数据模型

- `User`：账户、密码散列、角色、审批和启停。
- `Equipment`、`Supplier`、`Part`：设备、供应商和备件主数据。
- `Procurement`、`Inbound`：采购比价和入库批次。
- `InventoryTransaction`、`Stocktake`：库存流水和盘点纠错。
- `FaultReport`、`Withdrawal`：故障工单和维修领用。
- `Lifecycle`：单件备件安装时间、设计寿命和预警等级。
- `Disposal`：旧件修复、回库、复用或报废。
- `AuditLog`：关键动作的追加式审计记录。

### 3.4 库存和寿命规则

- 当前库存为 0：紧急缺货。
- 当前库存小于最低库存：低位预警。
- 当前库存大于最高库存：库存偏高。
- 建议补货量：`最高库存 - 当前库存`，最低为 0。
- 剩余寿命不超过 20%：一级预警；不超过 10%：二级预警；到期：三级预警。
- 维修领用只有在库存足够时才提交扣减，并同时写库存流水和审计日志。

### 3.5 中英文

- `EN_TRANSLATIONS` 保存翻译字典。
- `translate_english_text()` 处理单段文本。
- `translate_english_html()` 扫描最终 HTML 的文本节点和可见属性。
- `translate_english_response()` 在英文会话返回响应前执行完整翻译。
- JavaScript 还会处理少量浏览器动态文本，但不是英文功能的唯一依赖。

### 3.6 AI 助手

- `select_assistant_tools()`：按关键词/意图选择只读函数。
- `get_inventory()`：完整库存摘要。
- `get_low_stock()`：低库存和建议补货。
- `get_faults()`：故障状态。
- `get_lifecycle_alerts()`：寿命预警。
- `local_assistant_answer()`：把查询结果生成人类可读的中英文答案。
- `requires_exact_system_answer()`：精确系统事实禁止交给外部模型改写。
- `cloudflare_ai_answer()`：仅在适合时调用外部 API 做语言润色。
- `clean_ai_answer()`：拒绝提示回显、重复和异常内容。
- `consume_ai_request_slot()`：按用户限制每分钟外部 AI 调用次数。

AI 不能修改库存、批准采购或处理故障。外部服务失败后，系统自动回退到本地答案。

### 3.7 主要路由

| 路由 | 作用 |
|---|---|
| `/login`、`/logout` | 登录和安全退出 |
| `/register`、`/users` | 注册申请和管理员审批 |
| `/language/<lang>` | 切换中文/英文会话 |
| `/` | 数据驾驶舱 |
| `/parts`、`/equipment`、`/suppliers` | 三类主数据 |
| `/procurement` | 采购需求、报价和审批 |
| `/inbound`、`/stock` | 入库、库存、盘点和预警 |
| `/faults` | 后台故障与维修领用 |
| `/fault-report`、`/fault-report/qr.png` | 公开扫码表单和二维码图片 |
| `/lifecycle`、`/disposals` | 寿命动作和废弃件处置 |
| `/api/assistant/alerts` | AI 卡片只读预警摘要 |
| `/api/assistant/chat` | AI 只读问答 |
| `/export/<kind>.csv` | 按权限导出 CSV |
| `/healthz` | 部署和巡检健康状态 |

## 4. 安全边界

- 密码使用 Werkzeug 散列，数据库中不保存明文密码。
- 所有修改请求校验 CSRF。
- 登录和权限在服务器端判断，不能只依赖隐藏菜单。
- API 密钥、会话密钥和数据库路径保存在服务器环境变量中。
- 浏览器展示 AI 输出时使用 `textContent`，不把回答当作 HTML 执行。
- 安装更新明确排除生产数据库和 `production.env.ps1`。

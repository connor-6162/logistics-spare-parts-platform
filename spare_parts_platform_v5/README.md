# 物流设备备品备件智能预测与全生命周期数字化管理平台

本项目使用 Flask + SQLite 实现，可直接在普通 Windows/Linux 电脑本地运行。它覆盖基础资料、采购比价、登记入库、在库盘点、设备故障、领用出库、旧件处置、寿命三级预警和数据驾驶舱，并内置可操作的演示数据。

## 主要功能

- 设备、备件、供应商基础信息统一维护
- 实时库存低于安全库存时自动生成采购需求
- 多供应商报价对比、建议最低价与管理员审批
- 入库自动增加库存并沉淀供应商历史供货记录
- 盘点自动判断账实差异并形成库存纠错流水
- 移动端故障提报二维码、维修领用及库存校验
- 生产二维码固定使用 HTTPS 公网地址；手机扫码后直接进入免登录故障表单，并在审计日志标记扫码来源
- 领用完成后自动建立“一物一码”寿命档案
- 剩余寿命 20% / 10% / 到期的三级预警
- 安全核心件强制更换，其他件支持延期重算预警日期
- 旧件复用、残值处置、报废闭环
- 库存、预警、采购 CSV 导出与审计日志
- 中文 / English 一键切换，语言偏好随账户保存；V4 已覆盖全部业务模块、动态演示数据、弹窗、表格、提示和移动端故障提报页
- 账户自助注册、管理员审核启用与七类角色权限隔离
- 故障领用页提供本月和本年度损管比环形示例图

## 快速启动

建议使用 Python 3.10 或更高版本。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

浏览器打开 `http://127.0.0.1:5055`。V5 默认改用独立端口 `5055`，避免电脑上残留的旧版 `5000` 端口进程导致页面仍显示旧代码；页面右上角应显示 `V5` 标识。

演示账号：

| 用户名 | 密码 | 角色 |
| --- | --- | --- |
| `admin` | `Admin123!` | 系统管理员 |
| `worker` | `Worker123!` | 一线工人 |
| `warehouse` | `Warehouse123!` | 仓库人员 |
| `maintenance` | `Maintenance123!` | 维修工程师 |
| `procurement` | `Procurement123!` | 采购人员 |
| `manager` | `Manager123!` | 中层领导 |
| `executive` | `Executive123!` | 高层领导 |

系统默认 `DEMO_MODE=True`。每次启动都会恢复以上演示账户的预设密码、角色与启用状态，避免旧数据库密码导致无法登录。自行注册的账户默认处于“待审核”状态，由系统管理员在“用户与权限”页面分配角色并启用。

V3 登录增强：关闭密码自动填充、支持显示/隐藏密码、演示账号一键登录，并在演示模式下兼容密码首尾空格及全角感叹号。演示模式还会分别提示“用户名不存在”“密码不正确”和“账户等待审核”；生产模式仍使用统一错误提示，避免暴露账户状态。

V4 完整双语增强：英文模式会翻译页面标题、业务数据、状态、表头、表单标签、占位提示、确认提示和审计动态；侧边栏、驾驶舱指标及快捷入口中的单字中文图标会自动切换为大写英文首字母。

V5 采用服务器端完整英文渲染，并保留前端兼容翻译。即使浏览器缓存了旧脚本或 JavaScript 未加载，页面标题、动态演示数据、隐藏弹窗、下拉选项和提示属性也会直接以英文返回；HTML 页面同时禁止缓存，避免中英文版本串页。

首次启动会自动创建 `spare_parts.db` 并写入演示数据。若需重置演示环境，停止程序后删除该数据库文件并重新运行。

## 配置项

可以通过环境变量覆盖默认配置：

- `SECRET_KEY`：生产环境务必设置为随机长字符串
- `DATABASE_URL`：默认使用项目目录下的 SQLite
- `HOST`：默认 `127.0.0.1`
- `PORT`：默认 `5055`（仍可自行覆盖，例如 `$env:PORT="5000"`）
- `FLASK_DEBUG=1`：仅开发环境使用
- `DEMO_MODE=False`：关闭演示账户密码自动恢复（生产环境建议关闭）
- `PUBLIC_BASE_URL`：二维码使用的公网根地址；服务器部署设置为 `https://lwqgraduationproject.cn`

## AI 智能助手

助手的本地预警、关键词路由和只读查询不依赖外部服务；即使外部 API 超时或达到免费用量上限，库存、故障和寿命预警回答仍然可用。外部对话使用 Cloudflare Workers AI，密钥只保存在服务器环境变量中。

```powershell
$env:AI_PROVIDER = "cloudflare"
$env:CLOUDFLARE_ACCOUNT_ID = "你的 Cloudflare Account ID"
$env:CLOUDFLARE_API_TOKEN = "具有 Workers AI Read/Edit 权限的令牌"
$env:CLOUDFLARE_AI_MODEL = "@cf/meta/llama-3.1-8b-instruct"
```

助手只允许调用 `get_low_stock`、`get_faults` 和 `get_lifecycle_alerts` 三个只读函数，不具备新增、修改、审批或删除权限。不要把 API Token 写入 HTML、JavaScript、Git 仓库或聊天记录。

局域网演示可执行：

```powershell
$env:HOST="0.0.0.0"
python app.py
```

## 生产部署提示

当前版本适合本地验收和功能原型演示。正式部署前应修改默认密码和 `SECRET_KEY`，并按组织实际权限体系接入统一认证、备份数据库、配置 HTTPS，同时结合手持扫码器或企业移动端替换演示二维码入口。
